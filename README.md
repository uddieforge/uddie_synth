# uddie_synth
Repository for all things related to the arduino-based Uddie Synth

The Uddie synth is a synthesizer project based on the Mozzi library for Arduino. The idea was to build a synth using as few components as possible, while still making it a genuine tool for recording and live performances. The challenge was therefore to find the right balance between simplicity and functionality.

The result is a small, low-cost synthesizer featuring multiple waveforms, a sequencer, an AR envelope, and the ability to synchronize several synths together.

As I'm not a developer, the code was written using Claude-assisted vibecoding. There may be errors or questionable design choices. If anyone feels like rewriting the code in a cleaner, more proper way, I'd be happy to see that contribution.
